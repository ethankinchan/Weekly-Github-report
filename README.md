# Weekly GitHub Hot Repositories

1. Put these files in a GitHub repository.
2. Enable **Settings → Pages → Source: GitHub Actions**.
3. Run the workflow manually once, or wait for Monday 09:00 UTC.
4. The generated browser-readable report is published at the repository's GitHub Pages URL.

The ranking uses recent pushes, stars, and forks. GitHub does not expose one universal official field for stars gained in exactly seven days.
